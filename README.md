# Animal Attack

The playable digital adaptation of **Animal Attack**, Brent Short's original card game.

The physical game - including its artwork, rules, card concepts, names, and card details - was created by Brent Short circa 2020. This digital adaptation was developed in 2026.

## Card catalog

- 17 Attack cards
- 43 Support cards
- 37 Defense cards
- 97 unique cards total

The current game uses Brent's scanned original card artwork. The browser-friendly artwork is stored in 12 compact WebP sprite sheets so the complete game remains lightweight on GitHub Pages.

## Play

This version supports a two-player pass-and-play battle. Players choose their starting Attack card, inspect cards by clicking them, play an optional Support card, choose a basic or special attack, and respond with a Defense card. Abilities containing a player-selected "or" display an explicit choice.

Open `index.html` through a local web server or enable GitHub Pages from the repository's `main` branch.
